OSM は関東・四国 PBF を3回ストリーミング走査し、各 bbox の外側も経度±0.004°・緯度±0.003°（約300m）だけ候補ノードを保持した。全国 PBF/JRB は開いていない。面積・距離は各 bbox 中央を原点とする局所平面へ投影して計算した。建物の長辺・短辺・方位は footprint の凸包に対する最小面積回転矩形、隙間は footprint 境界間の最短距離である。0m は計算値0.05m以下とした。

以下の分布表は、特記がなければ「第1四分位 / 中央値 / 第3四分位 / P90 / P99 / 最大」の順である。

## 6. PLATEAU と屋根

PLATEAU 千代田区 zip は176 b3dmを1タイルずつ読み、最大展開タイルは10.54MiBだった。batch row 11,588件、_gml_id一意 11,588件（重複0）。同じ東京 bbox には2,473棟あり、計測高さは上表のとおり全2,473棟で取得できた。

屋根形状は判別できなかった。b3dm batch table に屋根形状属性がなく、GLB三角形から建物単位で陸屋根・切妻・寄棟・片流れを信頼できる分類にする処理は実装していない。参考に OSM `roof:shape` は千代田区40/2,551棟（flat 38、hipped 1、gabled 1）、高松11/4,933棟（flat 6、dome 1、gabled 3、pyramidal 1）、阿波0/513棟で、欠測が多すぎるため全体比には使えない。

## 測れなかったもの・解釈上の制約

- 河川幅は3地域とも width タグ0件で、推測せず「測定不可」とした。
- 阿波の階数・高さ、PLATEAUの屋根形状は測定不可。高松の明示 height は2件のみ。
- OSM PBF reader は relation 非対応なので、relation型の建物・緑地・水域 multipolygon は含まれない。
- 道路幅タグのカバレッジが極端に低く、特に郊外版 street は都市部標本からの暫定転用である。
- 同じ通りは「最寄りの同一 OSM way」で近似した。道路名をまたぐ連続wayの統合はしていない。
- 街区は3m raster近似であり、厳密なベクトル polygonize ではない。
- 面積率は取得できた closed way の面積合計で、重なりの union は取っていない。
- 方位・道路種別・寸法はこの3矩形の実測であり、日本全国への母集団推定ではない。

## 再実行

スクリプトはすべて `/tmp/townstats/` にある。`bash /tmp/townstats/run.sh` で PBF抽出→統計→PLATEAU→本レポートを再生成する。入力リポジトリは読み取りのみで、成果物・中間JSONはすべて `/tmp/townstats/` に出力する。
